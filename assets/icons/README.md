# VEXA//DECK icon

The approved square ASCII portrait with cyan VEXA lettering is the application icon.
The master is `vexa-icon.png`; PNG sizes 16, 24, 32, 48, 64, 128, 256, 512 and 1024
are resampled exports for the Qt window and Linux hicolor icon theme.

Source artwork: `output/imagegen/vexa-ascii-icon.png`, edited with the built-in
image generation tool from the user-provided `/home/mka/Downloads/vexa_icon.png`.
The editing prompt is saved in `output/imagegen/vexa-ascii-icon-prompt.txt`.
This portrait is used only as an app icon; the GUI center panel remains empty.

Run `/usr/bin/python3 tools/install_desktop.py` to install the menu launcher and icons.
